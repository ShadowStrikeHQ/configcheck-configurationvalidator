# configcheck-ConfigurationValidator
Validates configuration files (JSON, YAML, INI) against a schema definition provided as input. Reports errors for invalid data types, missing fields, or violations of defined constraints. - Focused on Verification of system and application configurations against defined security policies. Supports YAML and JSON configuration formats, custom rule definition, and automated remediation suggestions.

## Install
`git clone https://github.com/ShadowStrikeHQ/configcheck-configurationvalidator`

## Usage
`./configcheck-configurationvalidator [params]`

## Parameters
- `-h`: Show help message and exit
- `--format`: No description provided
- `--log-level`: Set the logging level.
